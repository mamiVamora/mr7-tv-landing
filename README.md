# MR7 TV - Landing Page

صفحة هبوط احترافية لتطبيق MR7 TV - تطبيق شامل لمشاهدة المباريات، الأفلام، والمسلسلات.

## المميزات

- تصميم عصري وجذاب
- متجاوب مع جميع الأجهزة
- إحصائيات مبهرة (9,500+ قناة، 19,800+ فيلم، 8,600+ مسلسل)
- أقسام متكاملة: الخدمات، المعرض، المميزات، الوكلاء، التحميلات
- تأثيرات حركية باستخدام AOS

## التقنيات المستخدمة

- HTML5
- CSS3 (تصميم مخصص)
- JavaScript (AOS للتأثيرات)
- Font Awesome للأيقونات

## كيفية الاستخدام

1. افتح ملف `index.html` في المتصفح
2. أو ارفع المشروع على GitHub Pages

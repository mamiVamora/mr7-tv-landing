# 🤖 MR7 TV AI Chatbot

شات بوت ذكي مخصص لموقع MR7 TV يعمل بتقنية **Google Gemini AI**.

## 📋 المميزات

- ✅ يظهر في جميع صفحات الموقع (13 صفحة)
- ✅ يجيب على أسئلة المستخدمين بذكاء عن:
  - روابط التحميل (Android, iOS, Smart TV)
  - الباقات والأسعار
  - الميزات والقنوات
  - طرق التفعيل
  - معلومات الاتصال
- ✅ تصميم عصري يتناسب مع هوية MR7 TV
- ✅ حفظ سجل المحادثة في المتصفح
- ✅ متجاوب مع جميع الأجهزة

## 🚀 طريقة التفعيل

### الخطوة 1: الحصول على مفتاح Gemini API

1. اذهب إلى: https://makersuite.google.com/app/apikey
2. سجل الدخول بحساب Google
3. اضغط على **Create API Key**
4. انسخ المفتاح

### الخطوة 2: تفعيل الشات بوت

**الطريقة الموصى بها (للمستودعات العامة):**

1. انسخ ملف `.env.example` إلى `.env`:
   ```bash
   cp .env.example .env
   ```

2. افتح ملف `.env` وضع مفتاح API الخاص بك:
   ```env
   VITE_GEMINI_API_KEY=AIzaSyBxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

**ملاحظة:** ملف `.env` محمي في `.gitignore` ولن يُرفع إلى GitHub.

**طريقة بديلة (config.js):**

إذا كنت تفضل استخدام `config.js`:
1. افتح ملف `bot/config.js`
2. ضع مفتاح API مكان `YOUR_API_KEY_HERE`

### الخطوة 3: اختبار الشات بوت

1. افتح أي صفحة HTML في المتصفح (مثلاً `index.html`)
2. ستجد زر الشات العائم في الزاوية السفلية اليسرى 💬
3. اضغط عليه وابدأ المحادثة!

## 📁 بنية الملفات

```
bot/
├── chatbot.html        # واجهة الشات بوت
├── chatbot.css         # تصميم الشات بوت
├── chatbot.js          # منطق الشات بوت + تكامل Gemini API
├── config.example.js   # مثال لملف الإعدادات
└── config.js          # ملف الإعدادات الفعلي (يحتوي على API key)
```

## 🔒 الأمان

- ملف `bot/config.js` محمي في `.gitignore` ولن يُرفع إلى GitHub
- لا تشارك مفتاح API الخاص بك مع أحد
- استخدم المفتاح فقط في المواقع الموثوقة

## 🎨 التخصيص

### تغيير الألوان

عدّل ملف `bot/chatbot.css`:

```css
:root {
    --chatbot-primary: #7c3aed;      /* اللون الأساسي */
    --chatbot-secondary: #fbbf24;    /* اللون الثانوي */
    --chatbot-accent: #3b82f6;       /* لون التمييز */
}
```

### تعديل المعلومات

عدّل `SYSTEM_INSTRUCTION` في ملف `bot/chatbot.js` لتحديث معلومات المشروع.

## ⚠️ استكشاف الأخطاء

### الشات بوت لا يظهر؟
- تأكد من أن ملف `bot/chatbot.js` موجود
- افتح Console في المتصفح (F12) وتحقق من الأخطاء

### الشات بوت لا يجيب؟
- تأكد من أنك وضعت مفتاح API صحيح في `bot/config.js`
- تحقق من اتصالك بالإنترنت
- افتح Console وتحقق من رسائل الخطأ

### رسالة خطأ API؟
- تأكد من صحة مفتاح API
- تأكد من تفعيل Gemini API في حساب Google Cloud
